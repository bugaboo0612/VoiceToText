# VoiceToCode

Нажимаете горячую клавишу, говорите — в то место, где стоит курсор (Блокнот, браузер, Claude Code, что угодно), вставляется очищенный текст. Всё работает на вашем компьютере — голос и текст никуда не отправляются в интернет.

## Установка на новом компьютере

Программа работает только на Windows с видеокартой NVIDIA (без неё тоже запустится, но распознавание речи будет заметно медленнее — на процессоре).

Самый простой способ — поставить [Claude Code](https://docs.claude.com) и попросить его помочь: он прочитает этот README и сам выполнит нужные команды. Но всё это можно сделать и вручную.

**Что понадобится поставить заранее** (если ещё не стоит):

1. [Python 3.14](https://www.python.org/downloads/) — при установке отметьте галочку «Add python.exe to PATH».
2. [Git для Windows](https://git-scm.com/download/win).
3. [Ollama](https://ollama.com) — локальный ИИ для чистки текста.
4. Свежий драйвер видеокарты NVIDIA (через приложение NVIDIA или сайт nvidia.com).

**Дальше — в PowerShell**, в папке, куда хотите поставить программу:

```powershell
git clone https://github.com/bugaboo0612/VoiceToCode.git
cd VoiceToCode
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
ollama pull qwen3:8b
```

Установка идёт минут 10-20, в основном за счёт загрузки библиотек и модели Ollama (≈5 ГБ). Модели распознавания речи скачаются отдельно, при первом запуске программы (тоже несколько гигабайт, один раз).

**Ярлык на рабочем столе** (необязательно, но удобно) — выполните ещё это, поправив путь на свой:

```powershell
$s = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:USERPROFILE\Desktop\VoiceToCode.lnk")
$s.TargetPath = "C:\путь\до\папки\VoiceToCode\run.bat"
$s.WorkingDirectory = "C:\путь\до\папки\VoiceToCode"
$s.Save()
```

Если что-то в установке пошло не так — самый быстрый способ разобраться: открыть эту папку в Claude Code и описать ему, что случилось (или показать текст ошибки).

## Как запустить

Дважды щёлкните по ярлыку **VoiceToCode** на рабочем столе.

Появится значок в трее (у часов, в правом нижнем углу экрана — может быть спрятан под стрелочкой «Показать скрытые значки»):

- **серый** — программа ждёт;
- **красный** — идёт запись;
- **жёлтый** — идёт обработка текста.

Первый запуск после установки занимает больше времени — скачиваются модели распознавания речи. Дальше запускается за несколько секунд.

## Как диктовать

1. Зажмите горячую клавишу (по умолчанию **F9**) и говорите. Отпустите — текст вставится сам.
   Если в настройках выбран режим «Переключение» — один раз нажмите, чтобы начать, и ещё раз, чтобы закончить.
2. Текст также остаётся в буфере обмена — если вставка почему-то не сработала, нажмите Ctrl+V вручную.

## Настройки

Правой кнопкой по значку в трее → **«Настройки…»**. Там можно поменять:

- горячую клавишу (кнопка «Изменить» → нажать нужное сочетание → «Сохранить»);
- режим клавиши (удержание / переключение);
- стиль по умолчанию (без обработки / обычный / вежливый / профессиональный) — стиль также можно быстро переключить прямо в меню значка;
- микрофон;
- модель Ollama, которая чистит текст;
- звуковой сигнал при записи — вкл/выкл;
- автозапуск вместе с Windows.

## Словарь замен и история

В меню значка:

- **«Открыть словарь»** — файл, где можно прописать свои замены (например, если какое-то слово или имя постоянно распознаётся неправильно). Формат: одна строка — одна замена, например `клод код = Claude Code`. Сохраните файл после изменений (Ctrl+S в Блокноте) — новые правила заработают со следующей диктовки.
- **«Открыть историю»** — последние 100 диктовок: сырой распознанный текст и итоговый (после чистки).
- **«Открыть папку данных»** — папка со всеми файлами программы (настройки, словарь, история, журнал ошибок).

## Если что-то не работает

**Горячая клавиша не реагирует.**
Проверьте, не запущено ли активное окно «от имени администратора» — из-за защиты Windows обычная (не администраторская) программа не видит нажатия клавиш в таких окнах. Это ограничение самой системы, а не поломка. Решение: работайте в обычных, не администраторских, окнах.

**Текст не вставляется, но программа явно что-то распознала (значок мигнул).**
Нажмите Ctrl+V вручную — текст уже лежит в буфере обмена.

**Текст вставляется без чистки, «как есть», хотя выбран не стиль «Без обработки».**
Скорее всего, не запущена Ollama — проверьте, что она работает (значок Ollama в трее или команда `ollama list` в командной строке). Без неё программа по-прежнему работает, но пропускает шаг чистки текста, чтобы вы точно не остались без текста.

**При запуске написано, что программа уже запущена.**
Значит, она уже работает — посмотрите значок в трее, вторая копия не нужна.

**Ничего не помогло.**
Откройте через меню значка «Открыть папку данных» и посмотрите файл `voicetocode.log` — там подробно записано, что происходило и на чём возникла ошибка. Можно показать этот файл тому, кто помогает с программой (например, Claude Code).

## Где что хранится

Все ваши данные — в папке `%APPDATA%\VoiceToCode`:

- `settings.json` — настройки;
- `dictionary.txt` — словарь замен;
- `history.txt` — история диктовок;
- `voicetocode.log` — журнал работы и ошибок.
