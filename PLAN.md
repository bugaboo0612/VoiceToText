# VoiceToCode — план разработки

> Этот файл — для вас и для Claude Code. Claude Code отмечает здесь выполненные пункты (`[x]`).

## 1. Что мы делаем

Маленькая программа, которая живёт в трее (значки у часов в правом нижнем углу). Вы нажимаете горячую клавишу, говорите — и через пару секунд туда, где стоит курсор (Claude Code, браузер, Word, мессенджер), вставляется аккуратный текст: без «ну», «э-э», «короче» и оговорок, в выбранном стиле.

Всё работает на вашем компьютере: голос и текст никуда не отправляются.

## 2. Как это будет выглядеть

1. Курсор стоит, например, в окне Claude Code.
2. Зажимаете **F9** (или нажимаете один раз — зависит от выбранного режима). Короткий сигнал, значок в трее краснеет.
3. Говорите: «Ну, э-э, короче, надо в среду… нет, в четверг созвониться по поводу, типа, релиза».
4. Отпускаете клавишу (или нажимаете ещё раз). Значок жёлтый — идёт обработка.
5. Примерно через 1–3 секунды появляется текст. В зависимости от стиля — примерно такой:

| Стиль | Результат |
|---|---|
| Без обработки | Ну, короче, надо в среду, нет, в четверг созвониться по поводу, типа, релиза. |
| Обычный | Надо в четверг созвониться по поводу релиза. |
| Вежливый | Давайте, пожалуйста, созвонимся в четверг по поводу релиза. |
| Профессиональный | Предлагаю провести созвон в четверг по вопросу релиза. |

Стиль переключается в меню значка в трее (правая кнопка мыши) и запоминается.

## 3. Что мы уже согласовали

| Вопрос | Решение | Простыми словами |
|---|---|---|
| Язык диктовки | русский с английскими словами | модель сама понимает, где русский, где английский |
| Распознавание речи | NVIDIA Parakeet TDT 0.6B v3 | бесплатная модель NVIDIA, понимает 25 языков, включая русский, сама ставит точки и запятые |
| Видеокарта | NVIDIA | распознавание почти мгновенное |
| Редактура текста | локальный ИИ через Ollama | «маленький ChatGPT» на вашем компьютере: бесплатно и без отправки текста в интернет |
| Горячая клавиша | оба режима, выбор в настройках | «держать и говорить» или «нажал — говорю — нажал» |
| Язык программирования | Python 3.14 (уже установлен) | для распознавания речи у Python лучшие готовые инструменты, а код проще читать |

## 4. Что я предположил — проверьте

Если что-то не так, скажите мне или Claude Code перед нужным этапом.

- Клавиша по умолчанию — **F9**. В настройках меняется на любую, в том числе на сочетание вроде Ctrl+Alt+Пробел.
- Текст **сам вставляется** туда, где курсор, и **остаётся в буфере обмена**: если вставка не сработала, просто нажмите Ctrl+V.
- **Короткий звук** при старте и остановке записи (можно выключить).
- Модель для редактуры — **qwen3:8b** (около 5 ГБ). Если качество на русском не устроит, на Этапе 4 сравним с другой.
- Программа хранит **историю последних 100 диктовок** в текстовом файле у вас на компьютере — чтобы ничего не терялось.
- Есть **словарь замен** — простой текстовый файл вида `клод код = Claude Code`, на случай если какой-то термин упорно пишется неправильно.
- Запуск — ярлыком. **Автозапуск вместе с Windows** — по желанию на Этапе 7.

## 5. Из чего состоит программа

Представьте конвейер из пяти работников:

1. **Уши** (`recorder`) — записывают звук с микрофона.
2. **Стенографист** (`recognizer`) — модель NVIDIA превращает звук в текст.
3. **Редактор** (`editor`) — Ollama убирает мусор и меняет стиль.
4. **Руки** (`paster`) — вставляют текст туда, где курсор.
5. **Пульт** (`hotkey`, `tray`, `settings_window`) — горячая клавиша, значок в трее и окно настроек.

## 6. Этапы

Каждый этап заканчивается тем, что что-то работает и это можно проверить руками. После каждого этапа Claude Code делает «сохранение» (коммит), поэтому всегда можно вернуться назад.

### Этап 0. Подготовка компьютера (делаете вы)

- [x] Python установлен (версия 3.14.7).
- [ ] Установить Git для Windows (git-scm.com) — нужен для «сохранений».
- [ ] Установить Claude Code (инструкция — на docs.claude.com).
- [ ] Обновить драйвер видеокарты NVIDIA.
- [ ] Установить Ollama (ollama.com) и скачать модель командой `ollama pull qwen3:8b`.
- [ ] Узнать объём видеопамяти: в командной строке выполнить `nvidia-smi`, посмотреть число после «/» в столбце Memory-Usage (например, 8192MiB = 8 ГБ). Сообщить Claude Code.
- [ ] Создать папку, например `C:\Projects\VoiceToCode`, и положить туда `CLAUDE.md` и `PLAN.md`.

**Готово, когда:** команда `py -3.14 --version` показывает Python 3.14.7, а `ollama list` показывает qwen3:8b.

### Этап 1. «Стенографист»: распознавание речи

Цель — убедиться, что модель NVIDIA хорошо понимает именно вашу речь.

- [x] Создать проект, «сохранения» (Git), окружение, `requirements.txt`.
- [x] Подключить распознавание Parakeet v3 (при первом запуске модель скачается).
- [x] Маленькая проверка: записать 5 секунд с микрофона и показать текст.
- [x] Запустить распознавание на видеокарте; если не выйдет — на процессоре, с объяснением, чего не хватает.

**Скажите Claude Code:** «Прочитай PLAN.md. Делаем Этап 1.»

**Как проверить:** запустите проверку и скажите: «Сегодня я открыл GitHub и запустил Claude Code». Текст должен появиться за секунду-две.

**Обратите внимание:** как записались английские слова — латиницей или русскими буквами. От этого зависит, насколько понадобится словарь замен.

### Этап 2. «Руки» и клавиша: первая настоящая диктовка

- [ ] Глобальная клавиша F9 в режиме «держать и говорить».
- [ ] Вставка текста в активное окно; текст остаётся в буфере обмена.
- [ ] Звуковой сигнал при старте и остановке записи.

**Как проверить:** откройте Блокнот, зажмите F9, скажите фразу, отпустите — текст появился. Повторите в браузере и в окне Claude Code.

### Этап 3. «Пульт»: значок в трее и второй режим

- [ ] Значок в трее: серый — ждёт, красный — запись, жёлтый — обработка.
- [ ] Меню значка: стиль, режим клавиши, «Настройки…», «Открыть папку данных», «Выход».
- [ ] Режим «нажал — говорю — нажал».
- [ ] Длинные диктовки (больше ~20 секунд): программа сама режет запись по паузам.
- [ ] Настройки сохраняются в файл и не сбрасываются после перезапуска.

**Как проверить:** переключите режим в меню, надиктуйте текст на минуту — он должен вставиться целиком. Перезапустите программу — режим сохранился.

### Этап 4. «Редактор»: чистка и стили

- [ ] Подключить Ollama. Инструкции для стилей — в папке `prompts` (их можно править самому в Блокноте).
- [ ] Четыре стиля: без обработки, обычный, вежливый, профессиональный.
- [ ] Защита: если Ollama не отвечает — вставляется текст без редактуры.
- [ ] Защита: если ИИ «ответил» на надиктованное задание вместо редактуры — вставляется текст без редактуры.
- [ ] Claude Code готовит 10–15 тестовых фраз (с паразитами, оговорками, английскими терминами), прогоняет их и показывает вам результаты. Сравниваем qwen3:8b с ещё одной моделью.

**Как проверить:** надиктуйте в Claude Code: «Ну, короче, напиши, э-э, функцию, которая, типа, сортирует список». Должна вставиться просьба «Напиши функцию, которая сортирует список», а не готовый код.

## 7. Как работать с Claude Code — памятка

- Запускайте Claude Code в папке проекта. Он сам читает файл `CLAUDE.md` при старте — поэтому файл называется именно так, а не cloud.md.
- **Один этап — один новый разговор** с Claude Code. Так он не путается в длинной истории.
- Начинайте фразой: «Прочитай PLAN.md. Делаем Этап N.»
- Если что-то пошло не так: «Верни проект к последнему сохранению и объясни, что случилось».
- Смело просите «объясни проще» — это записано в его правилах.
- Если Claude Code раз за разом делает что-то не так, попросите: «Добавь это правило в CLAUDE.md».

## 8. Риски и запасные варианты

| Риск | Что делаем |
|---|---|
| Английские слова распознаются русскими буквами («гитхаб») | ИИ-редактор исправляет известные термины, плюс словарь замен |
| Русский распознаётся хуже, чем хотелось бы | в той же библиотеке есть российская модель GigaAM v3 — переключение одной строкой, сравним на Этапе 1 |
| Не хватает видеопамяти на две модели сразу | переносим распознавание на процессор (работает чуть медленнее) или берём модель редактуры поменьше |
| ИИ-редактор иногда «отвечает» на текст вместо правки | строгие инструкции плюс автоматическая проверка ответа (Этап 4) |
| Клавиша не срабатывает в окнах, запущенных «от имени администратора» | это ограничение Windows; в обычных программах всё работает |
| Какая-то библиотека ещё не работает с Python 3.14 | ставим рядом Python 3.12 — версии не мешают друг другу, в проекте меняется одна команда |
| Первая обработка после долгого перерыва медленная | программа держит модель загруженной 30 минут и «прогревает» её при старте |

## 10. Словарик

- **Модель** — «мозг», обученный одной задаче (распознавать речь, править текст). Это файл, который программа загружает в память.
- **Ollama** — программа, которая запускает ИИ-модели для работы с текстом прямо на вашем компьютере.
- **Промпт** — инструкция для ИИ обычным языком.
- **Трей** — область со значками у часов в правом нижнем углу экрана.
- **Буфер обмена** — то, что вы копируете через Ctrl+C.
- **Библиотека** — готовый кусок чужого кода, который мы используем (например, для записи звука).
- **Виртуальное окружение (.venv)** — отдельная «коробка» с библиотеками только для этого проекта, чтобы не мешать остальной системе.
- **Коммит** — сохранение состояния проекта, как «сохранение в игре».
- **VAD** — детектор голоса: находит паузы, чтобы резать длинную запись на куски.
- **Видеопамять (VRAM)** — память видеокарты; в ней работают модели.
- **CUDA** — технология NVIDIA, позволяющая считать на видеокарте.
